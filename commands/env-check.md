按 `sys-setup` skill 跑一遍系统级环境体检（判读规则与修复命令以该 skill 为准）。

要求:

1. 先跑 `env_doctor.py`（Bash timeout ≥ 120s，出网被挡时它要先把超时耗完才能给结论），不要凭记忆预判缺什么；按打印顺序处理，标 `[未探测]` 的项先修前置再重跑。
2. **系统级软件不替用户装、不自动卸**：只报"要什么" + 脚本给的本平台示例命令，让用户自己执行；改全局配置前先问用户。Python 依赖不在体检范围（ModuleNotFoundError 跑 `python3 <plugin_root>/mcp/bootstrap.py --ensure`）。
3. 两类"装了 ≠ 能用"要看清：ffmpeg 缺编码器/滤镜只在渲染最后一步才炸；字体打印了路径也可能是缺口——结论说 cmap 无中文就是豆腐块（退出码 0），必须当缺失处理。
4. 收尾报告说**能力**而非包名：哪些工具可用/不可用（例："ffmpeg 无 libass → 字幕烧录不可用"）；标 `[-]` 是平台不适用，标"只降级不致命"的软项不阻塞纯剪辑任务。

只做环境，不要顺手开始剪辑任务。
